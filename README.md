# KalPa365 v6.4 – Pallomeri-korjaus

Pohjana v6.3; v6.2:n käyttöliittymä ja v5.9:n suorituskyky säilyvät.

- Lisätty Pallomeren tuore Liiga-uutislista `https://pallomeri.net/jaakiekko/liiga/`. KalPan vanha joukkuesivu ei sisällä kaikkia tuoreita uutisia.
- Lisätty julkaisijan Liiga-RSS varasyötteeksi.
- Pallomeren kokonaan luettaville lyhyille artikkeleille sallitaan vähintään 180 merkkiä artikkelin varsinaisesta sisällöstä (yleinen 450 merkin raja säilyy muille).
- Alkuperäinen julkaisupäivä, 30 päivän aikaraja, KalPa-aihe, maksumuuri- ja tuplasuodatus pysyvät käytössä.
- Kiekkoareenaa tai Google Newsia ei oteta takaisin.

## Asennus
Vaihda GitHubissa vain `KalPa365_palvelin.py`. `index.html` on mukana täyden paketin vuoksi, sitä ei tarvitse vaihtaa.

## Tarkistus
Paikalliset syntaksi-, linkki- ja lyhyen artikkelin tarkistukset tehty. Renderin verkkohakua ei ole voitu kokeilla tässä ympäristössä. Katso tarvittaessa `/api/sources`-sivulta Pallomeri.net.
